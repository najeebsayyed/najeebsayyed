## 👨‍💻 About Me

I am a Software Developer and aspiring AI Engineer with a background in building full-stack and mobile applications, currently focusing on production-grade AI-powered software systems.

- 💼 **Professional Experience**: Software Developer Intern at **GetCollab**, building responsive, scalable software solutions and developer tooling.
- 🎓 **Academic Foundation**: Pursuing a **BS in Data Science and Applications** at the **Indian Institute of Technology Madras (IIT Madras)**, grounding my engineering work in rigorous statistical learning, data structures, and computational mathematics.
- 🤖 **AI Engineering Focus**: Moving beyond basic LLM wrappers toward building robust, deterministic AI systems—specializing in structured generation, intelligent document intelligence pipelines, and real-time multimodal model integration.
